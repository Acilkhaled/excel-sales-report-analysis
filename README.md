# Excel Sales Report & Analysis

## Project Overview
This project focuses on organizing and analyzing car sales data using Microsoft Excel features and formulas.

## Tools & Features
- Number, date, and currency formatting
- Conditional formatting
- MAX and MIN functions
- SUM, COUNT, and AVERAGE calculations
- Salesperson performance analysis
- Lookup functions for car pricing
- Order total calculations
- Invoice and bill preparation

## Tasks Completed
1. Professional sales report formatting.
2. Highlighting the highest and lowest order amounts.
3. Applying target-based conditional formatting.
4. Calculating sales KPIs using Excel formulas.
5. Comparing sales performance by salesperson.
6. Retrieving car prices and calculating order totals.
7. Creating a formatted sales invoice.

## Skills Demonstrated
Microsoft Excel, spreadsheet analysis, formula-based calculations, data presentation, sales reporting, and business reporting.
